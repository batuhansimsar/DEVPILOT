# Contributing

Thanks for helping make DevPilot useful. Check existing issues and PRs before starting. Significant changes should be discussed in a focused issue. Always work on feature branches and never push directly to `main`.

Run `go fmt ./...`, `go vet ./...`, and `go test ./...` before opening a PR. Please include a real test fixture for diagnostic changes.

All diagnostic claims should be supported by evidence. Do not reveal secret values or run arbitrary repository scripts during inspection. Document the maintenance and security cost before adding dependencies.
