# Contributing

Open a focused issue or pull request with a reproducible developer problem. For new detectors, include fixture-based tests covering valid and malformed manifests, and ensure diagnosis never executes repository code. Avoid false claims of breakage. Run `go test ./...`, `go vet ./...`, and `go build ./cmd/devpilot` before submitting. Keep PRs small, and do not commit credentials or untrusted execution helpers. Review other open PRs before claiming a task.
